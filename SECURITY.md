# Security policy

DocMatch+ is a research / engineering prototype, not a clinically validated service. Do not submit real patient information to a test deployment.

## Report privately

Please use this repository's **GitHub private vulnerability reporting** feature. If it is unavailable, contact the maintainer through their GitHub profile to arrange a private channel before sending details. Do not publish exploit steps, credentials, patient data, or proof-of-concept material in a public issue.

Reports involving authentication, data exposure, facility isolation, routing integrity, or safety presentation are treated seriously. Include a concise impact description and reproduction steps using synthetic data only. Do not probe other users' or facilities' records.

The team will triage reports as capacity allows; no response time or bounty is promised. Security engineering checks do not establish fitness for clinical use. See the [README](README.md) for the project's current status and limitations.
